
# Sistema de Proyección para Cultos y Reuniones

**Proyektor** es la herramienta oficial diseñada para proyectar de forma limpia y dinámica himnos, alabanzas, coritos, la palabra y todo el contenido necesario durante nuestras reuniones.

La version adjuntada es la unica que cuenta con el Himnario IMPCH y diversidad de alabanzas "especiales" hasta el momento.

---

### 🖥️ Funcionamiento y Requisitos

* **Exclusivo para Computador:** Este sistema está desarrollado para funcionar **únicamente en equipos de escritorio (PC o Mac)**. No está optimizado para teléfonos móviles ni tablets.
* **Sistema de Controlador y Pantalla:** Funciona bajo un esquema de doble entorno:
  * **El Computador (Controlador):** Desde donde la persona a cargo selecciona las canciones, controla las letras y gestiona el orden de la proyección.
  * **La Pantalla Externa (Proyección):** El monitor, proyector o televisor secundario donde la congregación visualiza las letras en tiempo real.
* **Sincronización con el Repertorio:** El sistema está completamente vinculado al repertorio oficial de nuestro cancionero, indexando y mostrando únicamente las letras oficiales (excluyendo automáticamente aquellas notas que llevan el emoji 🔹).

---

### ⚙️ Método de Instalación y Uso

A diferencia de otros programas, **únicamente necesitas tener instalado Google Drive para escritorio** para sincronizar la carpeta del proyecto:

1. Instalar [Google Drive para escritorio](https://ipv4.google.com/intl/es/drive/download/) e iniciar sesión con el mismo correo electrónico con el que abras el archivo de **[Proyektor](https://drive.google.com/drive/folders/1R_mAUbI_SaVXGu5M5IJ-uXkvYeLR9dJ7)** (ojala con el mismo que se te compartió la carpeta del cancionero)

2. Abre tu explorador de archivos y dirígete a la carpeta compartida **"Proyektor"**.

3. Para ejecutar el programa, busca el archivo llamado **"Proyektor"**. 
   > 💡 *Nota:* Verás dos archivos con el mismo nombre; debes hacer doble clic sobre el que indica **Tipo: Archivo de secuencia de comandos de VBScript** al pasar el cursor por encima.

---

### 📝 Agregar o Corregir Canciones

Al igual que en el cancionero oficial, **solo es posible agregar alabanzas, coros o medleys de forma permanente a través del formulario de [[📥Propuestas]]** (Tambien aplica si se necesita otro himnario o version de la Biblia con las que cuenta el sistema de forma predeterminada) Todo aporte o corrección enviado por ese medio será revisado e integrado al repertorio principal para que aparezca automáticamente en Proyektor.

En caso necesitar agregar una alabanza o anuncio de forma rápida se puede pero no será permanente ya que se borrara al abrir el programa de nuevo.
